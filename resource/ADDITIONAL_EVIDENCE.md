# Additional scientific evidence

The original table/figure generator and its inputs are preserved unchanged.
Run the original prepare_assets.py as documented in README. Added files supply
selected numerical diagnostics and a source-version comparison table; they do
not change trained endpoints or the analytic theorem.

diagnostics/saved_oracle_* extracts 3,724 original scalar records. The posterior
array audit is a NEW ordinary-NumPy-FP64 check of 2,321 already stored arrays,
not a historical execution claim or outward-rounded proof. Its 1,403 missing
per-model training arrays remain unverified. Repeated arrays are not independent
samples. Source hashes/locators identify the data, which are not all bundled.

diagnostics/saved_deployment_audit.json preserves cache/native differences and
the original common-body hash plus unchanged flags. It does not invent separately
stored final-hash strings or newly computed tensor hashes. Native final gates
remain the scientific endpoints. Selected producer sources are provided for
inspection; these files are not the complete neural execution environment
or model corpus. Only the existing table/figure generator is standalone here.

diagnostics/saved_gradient_audit.json retains 99 existing checkpoint records:
69 full-native and 30 final-affine masks. These are conditional full-B eval-mode
diagnostics, not historical training gradients or independent recomputation.

The synthetic auxiliary roster documents the two failed final checkpoints on
their training diagnostic inputs, a later wave with five new paired seeds, and
the original score-stress protocol/endpoints. Training saturation does not imply
validation or support-wide saturation; later outcomes do not replace original
failures. Stress-test zero FW values use the recorded FP64 max-with-zero rule.

The original sampling and score-control summaries retain per-case aggregates,
parameters and outcomes. The capacity RNG seed is 222501+n in the pinned
score_controls.py; sampled inputs are reused across ratios for each n. This
does not produce 80,000 independent samples.

Score controls use NumPy float64 scores/posteriors and direct loss subtraction,
not an original stable log1p calculation. No score-grid NPZ was saved. The pinned
Gaussian generator adds an independent uniform [-1,1] coordinate, casts combined
inputs to float32, and computes marginalized posteriors in float64. Its original
source manifest is supplied; source inspection is not a fresh generator run.

The inverse-norm specification identifies inflated Frobenius bounds and exact
source versions. The reference-transition audit is a NEW read-only comparison:
v2/v3 coefficients and coordinate maps are byte identical. It reruns neither
the optimizer nor the conditional extended-precision certificate. Original
wide intervals, final records, and the original criteria protocols are retained.

warm_protocol_audit.json identifies the original warm cohort's hard-label CE:
one draw per training-B input (seed+4141), reused each epoch, shared by the paired
statistics modes. Its NEW read-only label/index byte comparison is not a replay
of original random draws or optimizer execution. Original jobs/labels/source are
included; no summary metadata was corrected because its hardCE label was valid.

The restoration/runtime extract preserves the original 4,713 binary-path hash/
loading flags and 59 manifest identities, linked clean-store receipts and GPU
runtime metadata. Separate CPU serialization versions are retained. This is a
NEW extraction of saved records, not fresh restoration/loading/inference or
independent authentication of historical execution. Payload bytes sum over
paths; shutdown means command accepted and SSH unreachable in the saved record,
not a direct physical observation or a statement about current host state.
The original cold_official_comparison_v1/output/summary.json supplies the three
teacher serialized-NPZ byte flags separately from 648 model flags. It matches
the comparison digest already recorded in the original compact replay audit.
